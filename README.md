# Airline Delay Performance and Operational Efficiency Analysis
## Project Overview                                                                                                                     This project analyzes airline delay performance to identiify operational inefficiencies,punctuality trends and recovery across different airlines. 
## Objectives                                                                                                                               -Compare airline performance.                                                                                                                       -Identify airlines with the highest delays.                                                                                                 - Analyze the relationship between flight distance and delays.                                                                              - Identify flights that recovered delays during the journey.                                                                                - Detect operationally inefficient flights.
## Tools Used                                                                                                                                       -Microsoft Excel                                                                                                                            -SQL Sever                                                                                                                                  -Python (pandas)                                                                                                                            - Power BI
##Files Included                                                                                                                              -Airline Delay Analysis Dashboard.pbix                                                                                                         -Airline Delay Analysis Dashboard.pdf                                                                                                          -Airline Delay Analysis Performance and Operational Efficient Analysis Report.docx                                                             -Airline delay cleaned.cvs                                                                                                                 -Airline_Delay_cleaned.ipynb                                                                                                                   -Airline_Delay_Cleaned_sql_queries.sql                                                                                           
## Key Insights                                                                                                                                 -Delta recorded the best on-time performance.                                                                                                -Emirates had the hightest numder of delayed flights.                                                                                        -Flight distance had little effect on arrival delays.                                                                                          -Several flights recovered departure delays before arival.
